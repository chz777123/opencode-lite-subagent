v1.0.0
这个面板只提供说明与命令复制。 OpenChamber 扩展只能增加 UI，不能安装 agent；真正的安装请在终端运行下面的命令。

安装（二选一）

不要同时使用两种方式：它们会提供同名的命令与 skill。

OpenCode 插件
opencode plugin add github:chz777123/opencode-lite-subagent
curl 安装器
curl -fsSL https://raw.githubusercontent.com/chz777123/opencode-lite-subagent/main/install.sh | bash

插件会把 5 个 agent 写到 ~/.config/opencode/agents/，并用 transform 注册命令与 skill； 全局权限和 AGENTS.md 指针需要手动添加，或改用 curl 安装器。

协议

  1. 门控：任务复杂不是授权。用户明确要求、敲 /scout 或 /review，才算授权。
  2. TaskCard：goal / scope / non_goals / acceptance；禁止粘贴聊天历史或 diff 原文。
  3. 派单：只读角色 ≤3 并行；worker 同工作区同时只允许 1 个。
  4. 宿主验收：父 agent 亲自复跑 acceptance、看 git status、精读 diff、抽查一条 path:line。
  5. 续接：第 1 次修复用原 sessionID；第 2 次仍不过就停下，按脏净状态回滚或交人。

5 条全局权限

  • subagent *ask
  • shell git push *deny
  • shell git clean *deny
  • shell git reset --hard *ask
  • shell rm -rf *deny

subagent: ask 是授权门。首次批准某个角色时选 always，OpenCode 会按 agent ID 落一条持久 allow。
